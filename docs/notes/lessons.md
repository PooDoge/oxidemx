# Lessons — radial-ai implementation run (2026-06-11)

One entry per correction; read at session start per the workflow.

- **iced 0.14 `Space::new()` takes no args.** `Space::new(w, h)` is older API; build `Space::new().width(..).height(..)`.
- **`iced::window::Screenshot` field is `rgba`, not `bytes`.** `{ rgba, size, scale_factor }`; size is in *physical* px (× scale factor on fractional-scaling displays).
- **Emoji glyphs (🧠 🕓 📌 🗑) don't render in iced's default font** — they silently produce empty space. Stick to glyphs in DejaVu/Cantarell coverage (✱ ◔ ✦ ✕ ➤ ⧉ ▸).
- **`df` on `/` reports 0 available on atomic/ostree systems** (read-only composefs). Measure `/home` (fall back `/var`, `/`) for a disk-free widget.
- **Don't regex-patch Rust with `[^}]*` across match blocks** — it eats nested braces. Patch with exact unique strings.
- **Clippy 1.96 default lints now include** `doc_lazy_continuation` (a doc line starting with `+` reads as a list item), `doc_overindented_list_items`, and `manual_is_multiple_of` (`x % n == 0` → `x.is_multiple_of(n)`). Pre-existing code needed a sweep before `-D warnings` could gate.
- **The Interactions API can't mix the built-in `google_search` with custom function declarations.** Adding custom tools to GeneralChat forced its search through the nested-custom `grounded_search` pattern SettingsCustomizer already used.
- **Vision shots on a live desktop race the real mouse**: pointer travel over the popped overlay legitimately activates the chat (the deliberate-travel rule working as specified). Capture the armed state with short delays, or read state from logs.
- **GNOME 50 blocks `org.gnome.Shell.Screenshot` for arbitrary callers** and the portal stalls without interactive consent. An env-gated in-process `iced::window::screenshot` hook (`OXIDEMX_VISION_SHOT`/`OXIDEMX_START_PAGE`/`OXIDEMX_VISION_DELAY_MS`) is the reliable capture path — and doubles as a future CI visual-test hook.
- **`resizable: false` window settings + one-shot `iced::window::resize`** on release-commit worked in testing where per-frame resizes historically desynced the wgpu surface; keep resizes rare and single-shot.
- **The black-background bug was the X11 backend, not size/alpha-mode/opaque-region.** A stray `WINIT_UNIX_BACKEND=x11` in the daemon's overlay spawner (slipped in via an unrelated docs commit) ran the overlay through Xwayland: the override-redirect window centres on the whole stacked X *screen* (straddling monitors) and composites opaque — every transparent region showed solid black while the menu was up. Diagnosis path that worked: `cat /proc/<pid>/environ` on the LIVE process (test instances I spawned myself ran Wayland and could never reproduce), then an A/B portal screenshot of forced-X11 vs Wayland instances. Wayland-first always; the daemon now pins `WINIT_UNIX_BACKEND=wayland`.
- **iced 0.14 layer caching serves stale GPU buffers for layers that stop changing** (layer-merging/reactive-rendering era, PRs #3033/#2662; siblings #3272/#3138/#3147 — our exact stale-at-idle variant is unreported upstream). Symptoms: frozen mid-animation meshes / quads stuck at mid-fade alpha under fresh text; `window::screenshot` pristine (it re-renders offscreen); correct during resize (full re-layout); reproduces on Vulkan AND GL. Mitigation: `chat_shell::cache_epsilon()` — frame-parity 1.0/0.999 multiplied into quad-layer colours + one invisible sub-pixel vertex nudged per frame in each canvas painter. `unconditional-rendering` does NOT help (it only forces redraw requests; the prepare-cache still serves stale buffers). Don't pin master (wgpu 28/29 breaks the wgpu 27 lockstep). Full write-up: docs/notes/iced-0.14-rendering-regressions.md.
- **Interactions API streams function-call args as `arguments_delta` JSON-string fragments** — `step.start` carries `arguments: {}`; folding only step.start executes every streamed tool call with empty args ("action argument missing"). Accumulate fragments by step index, parse at `step.stop` (`FnCallFold` in ai_client/sse.rs; tests carry the captured wire verbatim).
- **WGSL `vec3<f32>` struct padding is 16-byte aligned** — a `_pad: vec3` made the uniform block 96 B while the host Pod struct was 80 B; wgpu rejects at draw time ("buffer bound with size 80 where shader expects 96"). Use three scalar `f32` pads. The naga validation test can't catch host/shader size mismatches — only a live draw does.
- **Port shaders faithfully or re-derive**: the gridsun grid computed line thickness AFTER folding the time scroll into the coordinate → thickness grew unboundedly and the floor went solid within seconds (the original computes size from pre-scroll perspective depth). Screenshot verification must use a LATE timestamp (t=20 s), not the first frames.
- **`pgrep -x`/`pkill -x` silently match nothing for process names >15 chars** — `oxidemx-settings` is 16. Use `pgrep -f '^/usr/local/bin/<name>'`. Related: never `ps | grep <name> | kill` inside a script whose own command line contains `<name>` (the background wrapper's eval string matched; task killed itself, exit 144).
- **Duplicate overlays park forever in the D-Bus NameTaken→2 s-retry loop** — the daemon's spawner checks the bus name, but an overlay inside that backoff doesn't own it yet, so daemon restarts minted duplicates; three live instances fighting over focus made the AI page dismiss on open. Duplicates now exit(0) on NameTaken; vision/headless instances must skip the name claim entirely.
- **Write-time memory dedupe collapses near-identical texts** (Jaccard ≥ 0.7 same-scope → in-place update). Test fixtures like "entry 0"/"entry 1" silently merge (single-char tokens are filtered too) — give fixtures distinct multi-char token sets.
- **Weather popup placement**: the 484 px disc square only has ~85 px ring-free bands above/below the menu — a tall card cannot sit clear of the ring. Wide horizontal strip centered on the menu, placed top/bottom by the hovered slice's half, near-opaque fill decoupled from menu opacity.
- **`cargo fmt` (workspace-wide) reformats vendored crates** (iced_gtk_themer etc.) — always `cargo fmt -p <crate>...`, and `git checkout --` the drive-by noise before committing.
- **Parallel sessions on one checkout**: another session can switch the branch under you; commits land wherever HEAD is and `git push origin <branch>` then pushes nothing ("Everything up-to-date" is the tell). Check `git status -sb` before every commit/push; long-lived feature work goes in its own linked worktree. Full rules: docs/notes/multi-session-coordination.md.
