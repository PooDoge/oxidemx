Token gap — approvals have no “amber”

The canvas mockups use a peach for the approval state, but the iced Kit has no peach key. Decision needed: (a) map approvals to yellow (recommended — already caution), or (b) add a peach key to Kit::from_state and the theme palette. This spec assumes (a).

04

Radii & elevation

Radii step by role, not arbitrarily. Elevation is three cheap tiers built from a single iced::Shadow{color,offset,blur} — no spread, no inset (iced can’t). Focus uses a 1px accent border + faint glow, not a spread ring.

05

Icon set

One monochrome line set — 24×24 viewBox, 1.7px stroke, round caps & joins, no fill — replacing the ad-hoc Unicode glyphs (yellow). Color via currentColor, so each inherits its row’s ink. Ship as SVG handles cached the way device/OS glyphs already are.

06

Toolbar & IA consolidation

Today the chrome has two icon rows with overlapping jobs: the header toggles views, the thread strip mixes conversation context with config destinations — and “new chat” appears in both. The fix splits the two rows by what they govern: the header owns identity + view, the strip owns conversation context.
