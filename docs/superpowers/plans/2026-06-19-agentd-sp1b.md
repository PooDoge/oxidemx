# agentd (SP1b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `agentd` — a persistent, project-aware process hosting `oxidemx-agent-core` + `oxidemx-conductor` + the embedded `oxidemx-agent-local` model, exposed over `org.oxidemx.Agent` (zbus 5), with per-project transcripts/journaling and headless tests.

**Architecture:** A new `agentd` bin crate whose D-Bus-independent logic (project resolve/merge, per-project transcripts, journaling, the seam impls, model controls) is pure/trait-seamed and unit-tested with temp dirs + a recording `EventEmitter` + a mock `LocalModelService` — no live bus, no native engine on the default path. The thin `main.rs` + the `#[interface]` signal wiring + `mistralrs` sit behind the environmental edges (a `mistral` feature; an `#[ignore]` live-bus test). A separate light `oxidemx-agent-proxy` crate carries the `#[proxy]` client for SP1c clients.

**Tech Stack:** Rust, zbus 5, tokio, serde, AutoAgents 0.3.7; deps `oxidemx-agent-core`/`oxidemx-conductor`/`oxidemx-agent-local`/`oxidemx-shared`. Reference pattern: `daemon/src/dbus/{interface.rs,init.rs}` (server) + `overlay-rs/src/dbus.rs` (client).

## Global Constraints

- New bin crate `agentd`; new light lib crate `oxidemx-agent-proxy` (zbus + serde only — clients must NOT pull core/conductor/mistralrs).
- `mistralrs` reaches agentd only via `oxidemx-agent-local`'s `mistral` feature, gated behind agentd's own optional `mistral` feature (default OFF) — default build/tests never compile the native engine.
- D-Bus: `#[interface(name = "org.oxidemx.Agent")]`, single-instance via `connection.request_name("org.oxidemx.Agent")` (NameTaken ⇒ exit). zbus 5, mirroring `daemon/src/dbus/interface.rs`.
- **Project = working directory.** `project_key` = slug + short hash of the canonicalized cwd. Hybrid layout: project-local `<cwd>/.oxidemx/{skills,mcp.toml,config.toml}` merged OVER global `~/.config/oxidemx`; central `~/.local/share/oxidemx/projects/<key>/{transcripts/,runs/,journal.jsonl,learned/,meta.json}`.
- **agentd owns per-thread transcripts** (persisted jsonl). Every chat/flow D-Bus method takes a leading `project: &str` (cwd).
- Event emission goes through an `EventEmitter` trait (one production zbus impl + a recording test impl); the local model through `LocalModelService` (mock in tests). No live bus / native engine on the default test path.
- Lib hygiene: `#![forbid(unsafe_code)]`, no `unwrap`/`expect` outside tests, `thiserror` errors, `clippy -D warnings`, pristine build. `cargo test -p agentd -p oxidemx-agent-proxy` (default features) green after every task.
- Spec: `docs/superpowers/specs/2026-06-18-agentd-design.md`. Work in worktree `../oxidemx-phase1` on branch `phase1-local-llm-gateway`. Commit after each task. SP1c (overlay cutover) + SP-Learn + SP-Research are OUT of scope (SP1b only journals + reserves seams).

## File structure

```
agentd/
  Cargo.toml
  src/main.rs        # activation, request_name, build singletons, wire EventEmitter→signals
  src/lib.rs         # module decls + re-exports (so tests can reach the inner logic)
  src/error.rs       # AgentdError (thiserror)
  src/projects.rs    # ProjectKey, ProjectPaths, resolve/merge skills+mcp+config
  src/sessions.rs    # TranscriptStore (per project/thread jsonl) + hosts the SessionManager

  src/interface.rs   # AgentService inner struct + #[interface(name="org.oxidemx.Agent")] impl
oxidemx-agent-proxy/
  Cargo.toml
  src/lib.rs         # #[proxy] AgentProxy trait + small client DTOs
dist/systemd/oxidemx-agentd.service
dist/dbus/org.oxidemx.Agent.service
```
